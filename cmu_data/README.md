# CMU motion source used by the demo

`02_01.bvh` is the CMU Graphics Lab Motion Capture Database Subject 02, Trial 01 (walking), in the BVH conversion maintained at https://github.com/una-dinosauria/cmu-mocap/tree/master/data/002/02_01.bvh.

Original database: https://mocap.cs.cmu.edu/. The CMU site states the data is free for all uses, may be included in commercial products, but may not be resold directly (including converted form). Requested acknowledgement: “The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.”

The accompanying dog gait in `walk_with_dog.py` is procedural illustration, not motion-captured dog data.
